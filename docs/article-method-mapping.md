# Соответствие статье и реализации

Текущая версия реализует инфраструктурный MVP, предписанный ТЗ: чтение реального Level‑1B RA_BD1, инспекцию структуры и геолокацию пролёта. Она не объявляет орбитальный след обнаружением PMC.

| Компонент метода | Статус |
|---|---|
| Локальное чтение NetCDF4/HDF5 | Реализовано через h5wasm/WORKERFS |
| Поиск radiance, wavelength, latitude, longitude | Динамические кандидаты реализованы |
| Фактическая геолокация | Реализовано для latitude/longitude |
| Нормализация на irradiance | Не применяется без IR_UVN; режим residual radiance |
| SZA-binning и фоновая модель | Полином 4-й степени по каждому cross-track ряду, до 5 итераций |
| Residual и robust threshold | `signal − background`; `2.2 × 1.4826 × MAD` в bins 0,25° — приближение сезонного порога статьи |
| Три спектральных критерия | 283,0 / 287,0 / 291,5 нм, положительность, убывающий наклон |
| Морфология и connected components | Closing, optional opening, 8-связность, минимальный размер 3 |
| Detection score (не вероятность) | Эвристический ранг S/N + размер + спектральный спад |
| Параллакс для высоты 83 км | Следующий этап при наличии viewing angles |

До реализации следующих строк интерфейс не создаёт и не показывает синтетические кандидаты PMC.
